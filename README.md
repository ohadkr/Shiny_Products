# Shiny Products

קטלוג מוצרי שייני שנבנה עם React, TypeScript ו־Vite.

## הפעלה מקומית

```powershell
npm install
npm run dev
```

היישום קורא את המוצרים מהקובץ `DATABASE_SHINY.xlsx` בזמן הפעלה ובזמן בנייה.
לאחר עדכון האקסל, הריצו `npm run import:data` כדי לחדש את נתוני המוצרים.

## תמונות מוצרים

התמונות מוצגות לפי מק״ט ונשמרות ב־`public/products/`. המיפוי נמצא בקובץ
`src/data/product-images.json`; להוספת תמונה, שמרו אותה בתיקייה והוסיפו את
המק״ט ואת הנתיב למיפוי. נוספו תמונות לכל 439 המוצרים מתוך `Shiny 2026.pdf`;
כאשר הקטלוג מציג תמונה אחת למספר גדלים או אריזות, היא משותפת למק״טים
המתאימים. התמונות של המק״טים `0440` ו־`0441` הן דוגמיות צבע מהקטלוג.

## העגלה וייצוא הזמנה

הכמות הראשונית של מוצר בעגלה היא מכפלה אחת של הערך בעמודת `CAPACITY`.
ביטויי אריזה כמו `12X12` מחושבים כמכפלת המספרים, וערך ללא מספרים, כמו
`בודדים`, נחשב ליחידה אחת. אפשר לשמור את ההזמנה כקובץ Excel או להדפיס/לשמור
אותה כ־PDF דרך חלון ההדפסה של הדפדפן.

סיכום ההזמנה מציג סכום לפני מע״מ, מע״מ בשיעור 18% וסכום כולל מע״מ.
מוצרים ללא מחיר בקובץ יכולים להיכלל בעגלה ובייצוא; מחירם יוצג כלא זמין
והם אינם נכללים בסכום הביניים, בחישוב המע״מ או בסכום הכולל.
